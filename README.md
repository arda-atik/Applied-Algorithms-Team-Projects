# Applied Algorithms: Team Mini-Projects (CTU / ČVUT)

A collection of collaborative algorithmic mini-projects developed as part of the Algorithms coursework at the Czech Technical University in Prague (ČVUT). 

This repository focuses on empirical benchmarking, trade-off analysis, asymptotic optimizations, and real-world software applications.
